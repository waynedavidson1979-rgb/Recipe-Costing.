# Recipe Costing – Android app

1. Create a new (private is fine) repo on github.com.
2. Upload everything in this folder, including the hidden `.github` folder.
3. Open the repo's **Actions** tab → "Build Android APK" → wait ~5 min for the green tick.
4. Open the finished run, scroll to **Artifacts**, download `recipe-costing-apk`, unzip it.
5. Copy `app-debug.apk` to your phone and tap it (allow "install unknown apps" when asked).

Edit `www/index.html` and push again to get a new APK.
